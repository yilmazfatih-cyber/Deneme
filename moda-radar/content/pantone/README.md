# Pantone TCX tablosu

`tcx.json` renk bilimci tarafından açık hex veri kümesinden üretilir (kaynak: `docs/kaynaklar.md`). Alanlar: `kod`, `hex`,
`ad` (Pantone telifli, ikincil). Lab değerleri çalışma zamanında sRGB/D65 varsayımıyla hesaplanır (ADR-001).
Bu klasöre Pantone'un ücretli kütüphanelerinden veri kopyalanmaz.
