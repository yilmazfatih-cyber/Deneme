# Türkiye bağlam tabloları

- `takvim.json`: sezon açılışları (Ocak/Temmuz), Ramazan ve bayram tarihleri, okul takvimi.
- `iklim.json`: Marmara aylık normaller.
- `gelir.json`: TÜİK ilçe gelir sıralaması (segment haritası için).

P1'de doldurulur; `content/segmentler.json` bu tablolara kodla bağlanır.
