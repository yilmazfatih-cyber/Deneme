# İthalat ajanı çıktıları

Bu dal yalnız veridir; kod `ithalat-ajani/` klasöründedir. Günlük zamanlanmış tarama buraya yazar.

- `veri/ithalat.db`: taramalar, ilanlar ve her ölçüm (fiyat, Türkiye medyanı, kat, karar)
- `raporlar/tarama-*.md`: tarama raporları
- `raporlar/adaylar-*.json`: avcıların topladığı ham adaylar
