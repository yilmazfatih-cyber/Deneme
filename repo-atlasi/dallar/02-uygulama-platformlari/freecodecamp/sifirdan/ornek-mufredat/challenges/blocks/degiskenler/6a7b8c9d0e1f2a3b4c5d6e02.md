# --description--

Ters tırnakla yazılan şablon dizgileri, `${...}` içine yazdığın ifadeyi metne yerleştirir:

```js
const sehir = 'İzmir';
const mesaj = `Hoş geldin, ${sehir}!`;
```

# --instructions--

`selamla` fonksiyonu bir isim alsın ve `Merhaba, <isim>!` döndürsün. Şablon dizgisi kullan.

# --hints--

`selamla` bir fonksiyon olmalı.

```js
assert.isFunction(selamla);
```

`selamla("Zeynep")` çağrısı `Merhaba, Zeynep!` döndürmeli.

```js
assert.strictEqual(selamla('Zeynep'), 'Merhaba, Zeynep!');
```

Fonksiyon her isim için doğru çalışmalı (Türkçe karakterler dahil).

```js
for (const ad of ornekIsimler) {
  assert.strictEqual(selamla(ad), `Merhaba, ${ad}!`);
}
```

Şablon dizgisi kullanmalısın.

```js
assert.match(__helpers.removeJSComments(code), /`[^`]*\$\{[^}]+\}[^`]*`/);
```
