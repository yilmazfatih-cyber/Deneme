# --description--

JavaScript'te bir değişkene `=` (atama) işleciyle değer verirsin:

```js
let sayac;
sayac = 3;
```

Önce sağ taraf hesaplanır, sonra sonuç soldaki değişkene yazılır.

# --instructions--

`yas` değişkenine `30` değerini ata. Yorum satırının üstündeki koda dokunma.

# --hints--

Yorum satırının üstündeki kodu değiştirmemelisin.

```js
assert.match(__helpers.removeJSComments(code), /let\s+yas\s*;/);
```

`yas` değişkeninin değeri `30` olmalı.

```js
assert.strictEqual(yas, 30);
```
