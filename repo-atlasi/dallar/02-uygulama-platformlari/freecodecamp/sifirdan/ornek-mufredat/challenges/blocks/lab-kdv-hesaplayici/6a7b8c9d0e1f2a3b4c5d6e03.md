# --description--

Bir e-ticaret sitesi ürün fiyatlarını KDV hariç tutuyor. Sepette KDV dahil fiyatı göstermek için bir fonksiyon yaz.

**Kullanıcı hikâyeleri:**

1. `kdvliFiyat(fiyat, oran)` adında bir fonksiyon olmalı; `oran` verilmezse `20` kabul edilmeli.
1. Fonksiyon KDV dahil fiyatı iki ondalık basamağa yuvarlanmış bir sayı olarak döndürmeli.
1. `fiyat` negatifse ya da sayı değilse `RangeError` fırlatmalı.

```js
function kdvliFiyat(fiyat, oran = 20) {
  if (typeof fiyat !== 'number' || Number.isNaN(fiyat) || fiyat < 0) {
    throw new RangeError('Fiyat negatif olmayan bir sayı olmalı');
  }
  return Math.round(fiyat * (1 + oran / 100) * 100) / 100;
}
```
