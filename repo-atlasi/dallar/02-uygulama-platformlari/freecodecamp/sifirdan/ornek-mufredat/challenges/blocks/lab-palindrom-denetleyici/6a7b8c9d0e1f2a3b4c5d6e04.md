# --description--

Palindrom, tersinden okunuşu da aynı olan metindir: "kayak", "Ey Edip, Adana'da pide ye!". Boşluk ve
noktalama yok sayılır, büyük-küçük harf farkı da önemsizdir. Türkçede dikkat: `I` küçülünce `ı`, `İ` küçülünce
`i` olur; bunun için `toLocaleLowerCase('tr-TR')` kullan.

**Kullanıcı hikâyeleri:**

1. `palindromMu(metin)` adında bir fonksiyon olmalı ve `true` ya da `false` döndürmeli.
1. Harf olmayan karakterler yok sayılmalı, büyük-küçük harf Türkçe kurallarıyla eşitlenmeli.
1. Hiç harf içermeyen metin palindrom sayılmamalı.

```js
function palindromMu(metin) {
  const harfler = [...metin.toLocaleLowerCase('tr-TR')].filter((h) => /\p{L}/u.test(h));
  if (harfler.length === 0) return false;
  return harfler.join('') === [...harfler].reverse().join('');
}
```
