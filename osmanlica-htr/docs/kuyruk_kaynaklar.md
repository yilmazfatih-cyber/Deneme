# Etiketleme kuyruğundaki sayfalar

Tümü Wikimedia Commons'tan, göz kontrolüyle seçildi (çizim, tablo, matbu form, boş sayfa ve pasaportlar elendi).
Sayfaların 122'si kamu malı, 1'i CC0; bağlantılar köken kaydı içindir.

Lisans dağılımı: Public domain (122), CC0 (1)

Yeniden üretme: `scripts/commons_topla.py` → `scripts/commons_sec.py` → `scripts/commons_indir.py` → `scripts/kontak_sayfasi.py` (göz kontrolü)
→ `scripts/kuyruk_hazirla.py` → `scripts/kuyruk_yukle.py` → artifact yayımı (files: `kuyruk/*.jpg`) + ArtifactData `batch` (sayfalar koleksiyonu).
